If you make a jump and then the same jump back, you are on the start again, whichever way the first jump goes. When the first jump is to the left, the jump back is to the right, so adding a number undoes subtracting it. This works from every start and for every size of jump, because on the jump back you count on as many numbers as you counted back on the first jump. Only a jump of the same size gets you back, so you have to add the number you subtracted.

From 19, jump 8 to the left. You count back 8 numbers to 11, so `19 − 8 = 11`. On the jump back to the right you count on 8 numbers to 19, so `11 + 8 = 19`. From 11, a jump of 7 to the right would land on 18, one short of 19.

The point starts on 19, and the "Size of a jump" stepper is on [8](@size). You cannot press "Jump right" at first, because a jump of 8 from 19 would leave the line.

- Press "Jump left" and then "Jump right" to make the loop.
- Change the size, or drag the start to another mark, and make the loop again. If you cannot press a button, start with the other one.
- Watch the second line each time. Whatever the size and the start, its answer is the number on the "Start" readout.
