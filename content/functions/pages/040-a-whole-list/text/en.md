A machine does not care how many values are waiting. Feed it a list one value at a time and it gives back a list of the same length: [2, 4, 6, 8](@out).

This is called mapping a function over a list. The list goes in, the rule [× 2](@rule) is applied to each value, and the order stays the same.

Mapping takes a function as its input. A function that works with other functions is a higher order function.
