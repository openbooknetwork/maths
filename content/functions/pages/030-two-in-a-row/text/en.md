The output of one machine can be the input of the next. The value [3](@x) goes through f first and comes out as [6](@mid). Then it goes through g.

[g(f(3)) = g(6) = 6 + 3 = 9](@formula-out)

Read the formula from the inside out. The machine written next to the value runs first.

Now swap the machines. The same value through the same two machines gives a different result, because the order matters.
