A machine can also give a machine as its output. This one is called make. Drop in the number [3](@n) and it builds a new machine, h, whose rule is to add that number.

The new machine works like any other. Put in [4](@x):

[h(4) = 4 + 3 = 7](@formula-out)

Change n and make builds a different machine. One machine has made a whole family of them.
