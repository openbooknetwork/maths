A fair die has six faces, and each comes up with probability [1/6](@p-face).

Press Start and watch the die. Each bar counts the rolls of one face. The line across the bars marks the count each face can expect, which is the number of rolls times 1/6.

[expected = 0 × 1/6 = 0](@formula-expected)

After [0](@rolls) rolls, each face can expect [0](@expected). The run goes on to 600 rolls. The bars grow together and stay close to the line.

Which face leads changes from run to run. Press Start again and another face may take the lead.
