Each edge now has a length, like a road between two towns. The shortest route from [A](@from) to [G](@to) has length [11](@distance) and runs [A → C → B → D → F → G](@path). The number beside each vertex is its distance from [A](@from).

At the start this route has five edges, and the route A → B → D → G has only three. The shortest route is the one whose lengths add up to the least, however many edges it uses.

Pick Length, tap an edge and make it longer or shorter. The route changes as soon as another one becomes shorter. Pick Route to choose a new start and end.
