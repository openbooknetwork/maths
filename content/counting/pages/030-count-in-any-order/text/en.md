You can count a group of objects in any order you like, and you always end on the same number. Whichever object you start with, each one still gets one number, and you still say the numbers 1, 2, 3 in order. So you say as many numbers as there are objects. The order only changes which object gets which number.

Take three shells, one at the top, one in the middle and one at the bottom. If you count from the top down, the top shell gets 1 and the bottom shell gets 3. If you count from the bottom up, the bottom shell gets 1 and the top shell gets 3. Both times you end on 3, so there are three shells.

There are shells on the sand. Tap each shell once to count it. A dashed line joins the shells in the order you count them, so you can see your path.

- Count every shell, and look at the "How many" readout.
- Press Clear, and count them again along a different path. Start at the top, then at the bottom, then anywhere you like.

Whichever path you take, the "How many" readout ends on the same number.
