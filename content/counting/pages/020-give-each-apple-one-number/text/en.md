A count is right only when every object gets exactly one number. Since the numbers start at 1 and go up by one, the last number you say is how many numbers you said. That matches how many objects there are only when each object has one number.

Say there are five apples. If you skip one, only four apples get a number, so you stop at 4, one too few. If you count one apple twice, the five apples take six numbers between them, so you get to 6, one too many. When each apple gets one number, you finish on 5.

On this stall, a tap gives an apple the next number every time, even when it already has one. An apple you tap twice shows both of its numbers.

- Count the apples, but tap one of them twice, and watch the "Last number said" readout. It shows [0](@count) now.
- Press Clear and count again, and this time leave one apple out.
- Press Clear once more, and give each apple just one number.
