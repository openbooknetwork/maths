You can lay a number out as counters in rows of ten. Each row of ten counters is a full row, and the counters after the full rows make the last row. To compare two numbers, look at the full rows first. The number with more full rows is greater, because one more full row is ten counters, and a last row has 9 at most. If both numbers have the same number of full rows, those rows match, so the one with the longer last row is greater.

Take 35 and 71. 35 has 3 full rows and a last row of 5. 71 has 7 full rows and a last row of 1. The last row of 35 is the longer one, but 71 has more full rows, 7 against 3. Each of those 4 extra full rows holds ten counters, more than any last row can hold. So 71 is greater than 35.

Each block has its number above it, and a frame goes round the rows that decide which number is greater.

- Drag the "Second number" slider down to 43. The right block now has 4 full rows, still more than the 3 of the left block, so the frame stays on the full rows and 43 is greater.
- Then set the first number to 47. Both numbers now have 4 full rows, so the frame moves to the last rows, where 7 counters are more than 3.
