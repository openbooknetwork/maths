Once two groups are paired, you can tell which one has more. Each pair has one object from each group, so if the groups had only their paired objects, they would be the same. The objects left over are extra. The group that has them has more, and the other group has fewer. If nothing is left over, the groups are the same. This holds however much room a group takes up, because only the pairs decide.

Take a top row of 6 counters and a bottom row of 4. Each bottom counter pairs with a top counter, so there are 4 pairs and 2 top counters are left over. The top row has more than the bottom row. Said the other way round, the bottom row has fewer than the top row. Both sentences tell you the same thing.

The figure pairs these rows for you. A ring marks each counter left over, and a tag at the end of each row says how that row compares.

- Tap − on the "Top row" stepper until both tags read "the same".
- Tap it once more. Now a bottom counter is left over, so the tags swap.

The tags now read [more](@top-word) on the top row and [fewer](@bottom-word) on the bottom row.
