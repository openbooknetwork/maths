A set is a collection of things, and each thing in it is an element of the set. The circle is the set A. Right now A = [{🍎, 🍐, 🍒}](@A), which has [3](@count-A) elements.

Drag a fruit into the circle and it becomes an element of A. Drag it out and it leaves the set.

We write 🍋 ∈ A for "the lemon is an element of A". At the moment that statement is [false](@lemon-in-A).

There is one of each fruit, and a fruit is either inside the circle or outside it. So a set holds each element once. The order makes no difference, so {🍎, 🍐} and {🍐, 🍎} are the same set.
