Three circles cut the box into eight regions, one for each way an element can be in or out of A, B and C.

Only [5](@5) is in all three sets, so A ∩ B ∩ C = [{5}](@intersection).

A ∩ B = [{2, 4, 5}](@A-and-B) holds the elements A and B share. Take the elements of C away and (A ∩ B) ∖ C = [{2, 4}](@A-and-B-minus-C) is left.

The union A ∪ B ∪ C = [{1, 2, 3, 4, 5, 6, 7, 8, 9}](@union) holds every element inside a circle. [10](@10) is in no set at all.
