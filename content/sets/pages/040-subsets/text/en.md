A is a subset of B when every element of A is also an element of B. We write A ⊆ B.

Now A = [{a, b}](@A) and B = [{a, b, c, d}](@B). So A ⊆ B is [true](@A-in-B), and B ⊆ A is [false](@B-in-A).

Drag [a](@a) out of B and keep it in A. One element of A outside B is enough to make A ⊆ B false.

Empty A completely. The empty set is a subset of every set, so A ⊆ B is true again.

Can you make both statements true at once? Then the two sets hold the same elements, and A = B.
