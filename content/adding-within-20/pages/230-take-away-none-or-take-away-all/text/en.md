Two kinds of subtraction are easy to work out, whatever number you start with. If you take nothing away, the group stays as it was, so subtracting 0 leaves a number as it is. Adding 0 does the same. If you take every object away, nothing is left, so subtracting a number from itself gives 0.

Start with 7 counters. If you take none of them away, all 7 are still there, so you write `7 − 0 = 7`. If you take all 7 away, none are left, so you write `7 − 7 = 0`.

There are 7 counters in the frames, and none has been taken away yet. The number sentence is now [7 − 0 = 7](@written).

- Tap the counters away one at a time until no counters are left. Watch the number after = go down to 0.
- Set the "First number" stepper to 15. Every counter comes back, so nothing is taken away and the number sentence is `15 − 0 = 15`.
- Tap all 15 counters away, and check that the number after = is 0 again.
