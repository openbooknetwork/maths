You can add by counting on. The start is the mark where the point is before its first jump, and its number is the first number of the addition. You jump to the right as many times as the number you add, and the point lands on the sum. Subtracting works the same way with jumps to the left. The start does not count as a jump, because the point has not moved yet.

To add 3 to 9, say the start, 9, then count on one number for each jump: 10, 11, 12. So `9 + 3 = 12`. To subtract 3 from 9, say 9 and count back: 8, 7, 6. So `9 − 3 = 6`. Counting back works well when you subtract 1, 2 or 3. A longer count back is easy to get wrong.

The point starts on 9, inside a ring that marks the start. The number sentence under the number line follows your jumps. Before the first jump it reads `9 + 0 = 9`, because the point has made no jumps yet.

- Press "Jump right" three times. At each jump, the second number and the sum go up by one, and the first number stays 9.
- Press "Jump left" three times to take those jumps back, then three more times to subtract 3.
