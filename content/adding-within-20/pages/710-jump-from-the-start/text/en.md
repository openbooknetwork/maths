Your goal is to put the point on the number that an addition or a subtraction gives. You get there by jumping from the calculation's first number. For a + sign you count on, so you make as many jumps to the right as the number you add. For a − sign you count back, with as many jumps to the left as the number you subtract. The start is not a jump, so the first number you say is the one next to it.

Take `19 − 3`. You start on 19 and count back three numbers, one for each jump: 18, 17, 16. The third jump lands on 16, so `19 − 3 = 16`.

The goal line names the calculation, and the point starts on its first number, inside the start ring.

- Press "Jump right" or "Jump left" once for each number you count. No readout counts the jumps, so keep count as you go.
- Press Check when you think the point is on the right number. If it is not, a note tells you whether the point went the wrong way or how many jumps it made.
- When you get it right, the number sentence appears under the number line.
- Press Hint for help, and "Another one" for a new calculation.
