When you add two numbers, you find the number they make together. A calculation with the + sign, such as `4 + 3`, is called an addition. The number it gives is called the sum, and it tells you how many there are altogether. The two numbers are the parts, and the sum is the whole.

If one group gets one more counter, there is one more counter altogether, so the sum becomes the next number. If one group is empty, nothing joins the other group, so adding 0 leaves a number as it was.

Take `4 + 3`. 4 counters and 3 counters make 7 counters together, so the sum is 7. Give the first group one more counter and you have `5 + 3 = 8`, and 8 is the number after 7. Empty the second group and you have `4 + 0 = 4`.

The "First number" stepper sets the round red counters, and the "Second number" stepper sets the square blue counters after them.

- Press + on either stepper, and the sum becomes the next number.
- Set one number to 0, and the sum is the other number.
- Set both numbers to 6. The counters fill the first frame and 2 go on into the second, so the sum is 12.
