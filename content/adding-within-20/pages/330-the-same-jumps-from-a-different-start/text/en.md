Three jumps to the right add 3, wherever the start is. Each jump goes to the number after, so three jumps land on the third number after the start, which is the start plus 3. Three jumps to the left land on the third number before the start, so they subtract 3. The start gives the first number, and the number of jumps gives the number you add or subtract.

Start on 4 and jump three times to the right, to 5, 6 and 7, so `4 + 3 = 7`. From 15 the same jumps land on 18, so `15 + 3 = 18`. The first number and the sum change, and the 3 stays.

The point has already made three jumps to the right from the start on 9.

- Drag the start ring to 4, then 15. The point and its arcs move with it.
- Try to drag the start past 17. It stops there, because three jumps from 18 would go past 20, the end of the line.
- Drag the start back to 15 and press "Jump left" six times. The first three presses take the jumps back, and the next three subtract 3. Then drag the start to 8.
