A jump moves the point to the mark next to it, so it crosses one gap. The numbers go up by one from each mark to the next, so a jump to the right lands on the number after, and a jump to the left on the number before. If you start on 0 and jump only to the right, the number you land on is the number of jumps you have made.

Start on 0 and jump to the right five times. The jumps land on 1, 2, 3, 4 and 5. There are six marks from 0 to 5, because 0 has a mark too. But the point was already on 0 before it moved, so it crossed only five gaps. That is why you count the jumps to find how far the point has gone.

The point starts on 0. Each jump to the right shows as an arc above the line, and each jump to the left as an arc below it.

- Press "Jump right" five times, and count the arcs.
- Drag the point to 12, which clears the arcs.
- Press "Jump right" once to reach 13, then "Jump left" twice. The first press takes that jump back, and the second lands on 11.
