Your goal is to put the point on a number between 0 and 100. Only 0 and the tens have labels, and they are on the long marks. The point does not show its number, so you count from the labels. Find the long marks on either side of the number, and start from the nearer one. From the left one you count on, one jump for each number, and from the right one you count back.

Take 3 and 7. The number 3 is nearer 0, so you start on 0 and jump to the right 3 times. The number 7 is nearer 10, so you start on 10 and count back 9, 8, 7, which is 3 jumps to the left.

The goal line names your number, and the point starts on 0.

- Drag the point to the long mark you count from, then move it one mark at a time with "Jump left" and "Jump right". While the point moves, a window above it shows the nearby marks larger.
- Press Check when you think the point is on the number. If it is not, a note tells you which way to move it.
- Press Hint for help, and "Another one" for a new number.
