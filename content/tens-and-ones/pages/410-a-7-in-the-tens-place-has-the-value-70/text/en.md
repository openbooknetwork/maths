The value of a digit is the number it stands for in its place. A digit in the tens place counts tens, so its value is that many tens. A digit in the ones place counts ones, so its value is that many ones. So the same digit can stand for different numbers, depending on where you write it. This way of writing numbers is called place value.

Take 70. Its 7 is in the tens place, so it counts 7 tens, and its value is 70. The 0 in the ones place shows there are no ones, so its value is 0. Now add 7 ones to make 77. The new 7 is in the ones place, so its value is 7, while the 7 on the left keeps the value 70. The two 7s are the same digit, and only their places give them different values.

The chart starts with 7 rods and no cubes, and each digit has its value written under it.

- Press + on the Ones stepper until it shows 7. The value under the ones digit, now [0](@ones-value), goes up by 1 with each cube, and the 70 under the tens digit stays as it is.
- Then step the tens up or down. Each rod changes the value under the tens digit by 10, and the value under the ones digit stays the same.
