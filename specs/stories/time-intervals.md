# `time-intervals` Time intervals

- Level: beginner, building on the first ideas
- Needs: `telling-the-time`
- Leads to: none at the beginner level. The end page suggests `converting-units`, which changes hours to minutes
  and back.
- Sections: the time to the minute, minutes to the hour, how long from one time to another, finding the end time,
  finding the start time, seconds
- In the world: when a film at the cinema ends, the times of runners in a race on a stopwatch
- Figure: A clock face shows a start time and an end time, with the sweep of the minute hand between them shaded. A
  time line under the face shows the same stretch as a jump to the next hour and a jump on. The reader drags either
  pair of hands or steps the length, and the other end follows.
- Engine: new scenes `interval` and `stopwatch` in the `clock` family proposed in `telling-the-time`. `interval`
  draws two pairs of geared hands, one faded, shades the sweep between them, counts each whole turn as an hour, and
  draws the time line split at the hour. `stopwatch` has a seconds hand and a minutes count that run once when the
  reader presses Start, with a time slider to go back and forth through the run.

## Challenges

### Find how long it lasts
- Goal: The hours and minutes on the steppers equal the stretch from the start to the end.
- Drawn each time: A start time at any minute from 1:00 to 10:59 and a length from 6 to 110 minutes that crosses an
  hour. The hours stepper runs from 0 to 2 and the minutes stepper from 0 to 59. The page opens with the steppers
  at 0 hours and 0 minutes.
- Reached by: a stepper for hours and a stepper for minutes.
- Hidden: The length readout and the labels on the time line.
- Idea used: the time to the minute, how long from one time to another.

### Set the end time
- Goal: The end hands show the start time plus the length.
- Drawn each time: A start time at any minute from 1:00 to 9:59 and a length from 15 to 150 minutes, given as hours
  and minutes, whose end crosses an hour. The end hands open on the start time.
- Reached by: dragging the end hands in single minutes, with the hour hand following.
- Hidden: The digital display of the end and the length of the shaded sweep.
- Idea used: the time to the minute, finding the end time.

### Set the start to finish on time
- Goal: The start time plus the length gives the end time.
- Drawn each time: An end time at any minute from 3:30 to 11:59 and a length from 65 to 150 minutes, given only in
  minutes such as 95 minutes. The start hands open on the end time.
- Reached by: dragging the start hands in single minutes, with the hour hand following.
- Hidden: The digital display of the start and the length of the shaded sweep.
- Idea used: minutes to the hour, finding the start time, 60 minutes in an hour.
